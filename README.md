# CS203 Project G3-2


## Introduction
This project is an itinerary disruption tracker and alert system that takes in a user’s itinerary and searches for news regarding possible disruptions to it. By analysing the severity and timing of global incidents, the AI will evaluate the impact on the user’s itinerary and suggest modifications to it. The system will send alerts to the user when it detects significant disruptions, without the user’s prompting. Various factors, such as destinations, preferences and travel dates, will be considered to determine how relevant a particular disruption is to users’ plans, allowing for tailored responses for each user. Users are able to request more responses if the recommendations are not to their liking. The system will also support admins, who are able to manage user accounts.
